# 🗑️ Smart Dustbin Using Arduino

An automated, touchless trash bin built using Arduino Uno, HC-SR04 Ultrasonic Sensor, and SG90 Servo Motor.

## 📌 Features
- Automatic lid opening when an object/hand is detected within 20cm.
- Servomotor mechanism for smooth lid opening and closing.
- Contactless and hygienic waste management solution.

## 🛠️ Components Used
- Arduino Uno R3
- HC-SR04 Ultrasonic Sensor
- SG90 Servo Motor
- 9V Battery / Power Supply
- Jumper Wires & Breadboard

## ⚡ How It Works
1. The **Ultrasonic Sensor** continuously measures the distance in front of the dustbin.
2. If an object is detected within 20 cm, the **Servo Motor** rotates to open the lid.
3. The lid stays open for 3 seconds and then automatically closes.
